단계별 구현 과정 중 학습한 내용

안재윤: .env 파일을 이용해 민감한 API 키를 분리하고 안전하게 관리하는 방법을 익혔습니다. 그리고 requests 라이브러리로 외부 API 데이터를 수집하고 파일로 저장하는 전체 흐름을 실습했습니다.

추예지: 수집한 도서의 제목과 요약문을 텍스트 데이터에 그치지 않고, gTTs 라이브러리를 연동해 오디오 파일로 자동 변환 및 저장하는 파이프라인을 실습했습니다.

어려웠던 부분

안재윤: 수많은 JSON 데이터 속에서 특정 정보가 누락되었을 때 프로그램이 멈추지 않도록 예외 처리하는 과정이 까다로웠습니다. 그리고 생성형 AI가 부연 설명을 섞지 않고, 파이썬에서 곧바로 디코딩할 수 있는 완벽한 JSON 형태로만 응답하도록 통제하는 것이 어려웠습니다.

추예지: 도서 검색 결과 중 일부 항목에 요약글이나 가격을 특정 필드가 빠져 있어 파싱 중 KeyError가 발생하는 문제가 있었습니다. 이를 방지하기 위해 get() 메서드 활용 및 방어적 에러 핸들링 코드를 작성하는 과정이 까다로웠습니다.

새로 배운 것들

안재윤: OpenAI API의 temperature 값과 response_format 파라미터를 조작하여 AI 답변의 일관성을 높이고 출력 형식을 강제하는 프롬프트 엔지니어링을 새롭게 배웠습니다. 그리고 파일 경로를 다룰 때 pathlib 모듈을 사용하여 디렉토리 생성 및 파일 입출력을 훨씬 직관적으로 처리하는 법을 알게 되었습니다.

추예지: OpenAI API의 temperature 설정과 response_format 옵션으로 생성형 AI의 결과물 일관성 및 JSON 구조를 강제하는 법을 익혔으며, pathlib 모듈의 Path 객체를 활용해 mkdir(exist_ok=True) 방식으로 폴더 생성과 파일 입출력을 직관적으로 제어하는 기술을 배웠습니다.

느낀 점

안재윤: 외부 데이터를 수집하는 것에 그치지 않고 가공, AI 분류, 음성 파일 생성까지 하나의 자동화된 서비스 파이프라인으로 연결해 보는 경험이 유익했습니다. 그리고 외부 API를 연동할 때는 예상치 못한 빈 데이터나 예외가 자주 발생하므로, 꼼꼼한 에러 핸들링과 방어적인 코드 설계가 필수적이라는 점을 체감했습니다.

추예지: 단순 수집에 그치지 않고 AI 분류와 TTS 음성 합성까지 연결하며 전체 서비스 흐름을 구축해본 점이 매우 유익했으며, 불안정한 외부 API나 LLM 연동 시 예상치 못한 예외 데이터에 대비한 꼼꼼한 예외 처리의 중요성을 체감했습니다.
